# Your original hand-drawn sketch is required

The assignment requires a sketch drawn on A4 paper. Its rubric assigns zero for a sketch created with digital tools. Therefore this folder intentionally contains guidance, not a fabricated hand-drawn submission.

Use your existing submitted sketch if it matches the final page. Otherwise resolve any mismatch with your tutor rather than claiming the sketch predates the implementation.

On paper, plan at least four clear story sections, with the final measurement section if space allows:

1. **National picture:** title and introduction; national waffle; historical count/rate trend; two-period slope graph.
2. **Who:** overall age profile; age × sex heatmap.
3. **Population differences:** disadvantage connected dots; remoteness bars; health-characteristic profiles.
4. **Geography:** linked choropleth, proportional symbol map and non-contiguous area cartogram.
5. **Measurement and sources:** observed test cross-classification, limitations, takeaway and sources.

Sketch the actual page structure: narrow left text column, wider right chart column, shared alignment edges, generous section spacing. Include representative axes, legends, intended annotations, controls and the roles of colours. Use another sheet if needed to keep all diagrams legible.

Scan or photograph the real pages, convert to PDF, and save as `sketch.pdf` here. Publish that PDF on GitHub and use its actual URL in the submission template. The sketch PDF is not included in this delivery because it must be your original hand-drawn work.
