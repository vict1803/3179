# Run the updated dashboard

1. Extract the ZIP into a new folder.
2. Open a terminal inside `diabetes-australia`.
3. Run `python3 serve.py` (Windows: `py serve.py` if needed).
4. Open http://localhost:8000 in your browser.
5. Stop the server with Ctrl+C.

VS Code Live Server is another option. Double-clicking `index.html` shows static SVG previews; run the server for animation, navigation and chart interactions. No npm install or internet connection is required to display the charts.

The navigation, chart alignment, 1,000-square waffle replay and map exploration controls are already connected. Existing HTML/CSS comments are retained. See `docs/EDITING_GUIDE.md` for later edits.
